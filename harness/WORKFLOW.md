name: Poteto mode
description: "pstack's poteto-mode on every task in this conversation."
---

Poteto mode is on. Run each task in this conversation as if the user had selected `$pstack` for it. Before your first tool call on a new task, load the `pstack` skill and follow it. A pstack skill the user names, such as `/how` or `/arena`, runs in place of poteto-mode for that task.

pstack decides how the work runs, from its playbook and subagents to its autonomy rules and its reply. The Precedence section of the pstack adapter names the Mixdog rules that still apply.
